## 二、制作方法（流程纪律）

1. **安全稿先行**：脚本过证据结构（三组样本等）→ 所有者确认 → 才进制作；叙事性声称画面标「示例」。
2. **时间轴即骨架**：所有动效与音效锚点 = `T` 锚点表 + 句内时间 ft；段触发元素禁止用场景时间（曾导致急推"过期"与音画错位）。
3. **动效三层**：入场（弹入/翻转/飞入，非线性缓动+加速错峰）→ 常驻（浮动/流光/漂移，让画面"活着"）→ 打击点（冲击波/震屏/粒子，全片 ≤3 处，关键信息落定后 hold ≥1s 呼吸）。
4. **字幕纪律**：有效字高 ≥56px；容器必须按实测行宽显式设宽；改排版先跑 node 断言再渲染。
5. **验收门**：不把首检交给所有者——抽帧 → 独立验收 → 修复 → 复验；修 bug 用像素探针/二分变体定位，不猜。
6. **确定性渲染**：哈希伪随机（`rnd(i)`），禁 `Math.random`/`Date`，逐帧可复现。
7. **成本纪律**：SFX 只为新关键变化增加；Remotion 版本钉死 + Headless Shell 跨项目复用；渲染双版本一次排程。

## 三、踩坑记（工程教训，复用时先读）

1. flex 布局中的 SVG 必须显式锁定 CSS width/height，否则被拉伸产生越界绘制（001 的"神秘竖线"）。
2. remotion 4.0.534 渲染 WebSocket 断连 → 钉 4.0.533；配套 Headless Shell 可从旧项目复制，跳过慢速下载。
3. edge-tts 偶发断流会留下半截 mp3：生成后 ffprobe 校验，坏文件删除重试；manifest 防止改稿复用旧配音。
4. **绝对定位 + left:50% 且无显式宽度的容器，会被浏览器按剩余空间（约 960px）收缩换行**——字幕容器必须显式设宽（002 四行字幕事故根因）。
5. 场景索引位移时的批量字符串替换会互相踩踏（`===13→15` 后再 `===15→17` 会命中已改块）：按内容定位 + 逐项断言。
6. 深色玻璃卡片 + 模糊层会显著推高码率：华丽版渲染后用 CRF 23 重压。
