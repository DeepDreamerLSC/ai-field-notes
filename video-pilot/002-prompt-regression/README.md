## 保留的逐句易懂性修订

s01：“改了提示词，AI 提取对了一条订单的金额。就能换上新提示词吗？”

s02：“先别急。新提示词可能让另一条订单的金额，从提取正确变成错误。”

画面先明确“优化AI＝修改给AI的指令／提示词”，再展示分别标有新旧提示词输出的订单金额。每拍仍只突出一个主体。

- s04／s07／s08／s14／s19：把旧版、新版、本版、换版统一到具体提示词；明确改变的是AI对订单金额的提取结果。
- s09–s13：改稿、题、保护集、留出不再独立承担解释；直接说明存下哪些订单、查什么错误、何时补新订单。画面“查旧错／守旧对／测新例子”分别对应修复／保护／留出。
- s16–s20：清单写成动作，保存原文与正确答案、写清怎么算通过、查旧错旧对新例子、新旧提示词前后同测、新错误加入下次检查。
- 保留v3.4的单焦点时序、中性标准100、唯一运动2024、三组逐组显示与结尾完整3+2卡；逐句分镜记录focus_target／focus_enter／focus_exit，关键动作列出实际秒数和帧数。
- 口播仍只说“看个例子”，不朗读合成／非实测制作说明。画面小角标与制作文档保留证据边界。

六层认知结构与八项审稿答案继续放在同一分镜文档；不增加通用内容框架。全文20句逐句核对主体、变化对象、术语与前后承接；这属于开发内容自检，不能替代陌生观众理解验证。

## 复现步骤

在本目录执行；任一步失败则停止，修复后再复制当前音频与时间轴。前置条件同第一条：macOS中文字体、Python 3、`ffprobe`、Node 26、npm 11；`edge-tts==7.2.8`需要网络，首次渲染需下载Chrome Headless Shell。换字体后重新检查布局。

```bash
set -e
python3 -m venv .venv
.venv/bin/pip install edge-tts==7.2.8
.venv/bin/python test_narration.py
.venv/bin/python narration.py

cp timing.json ../001-customer-agent-three-questions/remotion/src/video002-timing.json
mkdir -p ../001-customer-agent-three-questions/remotion/public/narration002
cp narration/*.mp3 ../001-customer-agent-three-questions/remotion/public/narration002/
.venv/bin/python test_video.py
cd ../001-customer-agent-three-questions/remotion
npm ci
npx remotion render src/video002.jsx Video002 ../../002-prompt-regression/002-prompt-regression-16x9.mp4 --crf=18
```

外部TTS不保证重新生成的字节完全相同。改文本、音色、逐句语速或停顿后重新生成并复制完整当前音频与时间轴，再渲染。词语时间戳与声音SHA在时间轴入库；MP4、MP3与中间产物不入库；公开发布仍须所有者决定。

**观看前单独记录原判断：** 你改了提示词，AI提取对了一条订单的金额，就能换上新提示词吗？为什么？记录原话，随后不给答案提示、不补讲背景，再完整观看。

另外在分镜的焦点进入处暂停，先不提示答案，记录“此刻第一眼看哪里”“是否有两个重点竞争”“此前视线如何移动”及实际时间码；再静音完整播放，记录是否能跟随提示词变更→金额→规则→一条正确→尾号→另一条错误→先别换提示词。此测试尚未执行。

观看后独立回答：

1. 前10秒，你看到了什么矛盾？
2. 片中到底在完成什么任务，正确金额怎样确定？
3. 为什么会先试“取最后一个数字”；这算成熟方案吗？
4. 哪个事实让你改变或坚持原判断？这次提示词改动应采用还是暂不采用，依据是什么？
5. 三组样本分别检查什么；没用来改提示词的订单被用于继续修改后，应怎样处理？
6. 下次改提示词你会怎样验证；三组都过能说明多大范围？
7. 哪个主体、对象或背景没交代清楚，让你需要猜？哪段像只在听结论，而没理解过程？
8. 你愿意收藏或转发检查卡吗？为什么？
