## Issue #9：六层认知结构

观众模型与预期认知变化是本次设计假设，尚无真实盲看证明。

| 层 | 本片的具体设计 |
| --- | --- |
| 起点 | 面向正在用AI处理业务文字、没有评测背景的观众；假设其容易把“原来提取错的订单重测正确”当成换上新提示词的充分理由。 |
| 场景 | 从订单备注提取应付或实付金额。A含合计120、优惠20、应付100；要输出100，不能误取合计。用1–2句补齐任务和正确答案。 |
| 合理动作 | A的应付金额恰好在最后，因此可以先试“取最后一个数字”作为候选改动；局部重跑得到100是初始证据，不是成熟提取方案或上线授权。 |
| 冲突 | B的正确答案固定为80，尾号2024不属于金额。旧提示词输出80正确、新提示词输出2024错误，直接推翻“修好A就能换上新提示词”的判断。 |
| 抽象 | 数字位置不是任务语义；只验证用于改提示词的样本，会把局部修好误当成整体变好。 |
| 方法 | 固定输入、预期和通过条件；一次只改一项、前后同跑；查修复／保护／留出，新的失败加入保护。三组全过仍只证明这些样本，需按风险重复运行与扩大覆盖。 |

## 八项前置审稿答案

1. **观众与原判断：** 非评测专业的AI使用者；待验证假设是“错误订单修好了，可以放心换上新提示词”。
2. **最小背景：** AI在订单备注里找应付或实付金额；A真正答案100，B真正答案80，合计与尾号不能作答案。
3. **当时为何看起来合理：** A末尾刚好是应付金额，试一句位置规则能快速检验局部猜测；A重跑答对会产生正反馈。合理的是受控试改，不是据一条订单宣布方案成熟。
4. **推翻判断的事实：** 同一B输入、同一预期80，原先正确的80被新规则改成2024；A的成功不能抵消这个新回归。
5. **可迁移机制：** 把一个样本的表面规律当作任务规则，且只复测改提示词样本，遗漏了已有能力的损失。
6. **新的判断与行动：** 换上新提示词前同时检查修复、保护、留出；当前例子保护失败、留出未测，暂不采用新提示词；任何全过结论都限定到实际检查的样本。
7. **承担认知变化的视觉：** 数字钩子暴露冲突，稳定A备注建立场景，A末尾高亮解释局部动机，B尾号沿曲线移入输出解释因果，三项状态呈现决策与未验证部分。
8. **可保存资产：** 编号01–05的3+2“改提示词前检查卡”，保留前后同跑；末尾无字幕停留供阅读。能否实际带走方法须真实盲看验证。

### 保留的逐句易懂性修订

- s01先点明AI优化方式是修改指令／提示词，问题是能否换上新提示词，不暗示换模型、换系统或改权重。s02明确变错的对象是另一条订单的金额提取；不说无主体的“原本正确的”。
- s04／s07／s08／s14／s19把旧版、新版、本版、修好一题、换版统一到具体提示词与订单金额。s09–s13把改稿、题、保护集、留出解释成能操作的订单检查，不要求观众先懂评测术语。
- 画面先标新旧提示词输出；三组以“查旧错／守旧对／测新例子”为主，分别对应修复／保护／留出。最终资产写“保存原文与正确答案、写清怎么算通过、旧错／旧对／新例子、一次只改一项前后同测、新错误加入下次检查”。
- 保留v3.4单焦点时序：主题→A→B金额变错；标准答案中性；2024飞行时周边静止；三组逐组显示；最后才完整卡片。讲解期间不跳编号，末尾无字幕4秒。不得以静态截图漂亮冒充动态理解通过。
