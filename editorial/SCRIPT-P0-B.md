## Issue #9：六层认知结构

观众模型与预期认知变化是本次设计假设，尚无真实盲看证明。

| 层 | 本片的具体设计 |
| --- | --- |
| 起点 | 面向正在用AI处理业务文字、没有评测背景的观众；假设其容易把“失败题重跑答对”当成换新版的充分理由。 |
| 场景 | 从订单备注提取应付或实付金额。A含合计120、优惠20、应付100；要输出100，不能误取合计。用1–2句补齐任务和正确答案。 |
| 合理动作 | A的应付金额恰好在最后，因此可以先试“取最后一个数字”作为候选改动；局部重跑得到100是初始证据，不是成熟提取方案或上线授权。 |
| 冲突 | B的正确答案固定为80，尾号2024不属于金额。旧版80正确、新版2024错误，直接推翻“修好A就能换新版”的判断。 |
| 抽象 | 数字位置不是任务语义；只验证用于改稿的样本，会把局部修好误当成整体变好。 |
| 方法 | 固定输入、预期和通过条件；一次只改一项、前后同跑；查修复／保护／留出，新的失败加入保护。三组全过仍只证明这些样本，需按风险重复运行与扩大覆盖。 |

## 八项前置审稿答案

1. **观众与原判断：** 非评测专业的AI使用者；待验证假设是“错题修好了，可以放心换新版”。
2. **最小背景：** AI在订单备注里找应付或实付金额；A真正答案100，B真正答案80，合计与尾号不能作答案。
3. **当时为何看起来合理：** A末尾刚好是应付金额，试一句位置规则能快速检验局部猜测；A重跑答对会产生正反馈。合理的是受控试改，不是据一题宣布方案成熟。
4. **推翻判断的事实：** 同一B输入、同一预期80，原先正确的80被新规则改成2024；A的成功不能抵消这个新回归。
5. **可迁移机制：** 把一个样本的表面规律当作任务规则，且只复测改稿样本，遗漏了已有能力的损失。
6. **新的判断与行动：** 换新版前同时检查修复、保护、留出；当前例子保护失败、留出未测，退回新版；任何全过结论都限定到实际检查的样本。
7. **承担认知变化的视觉：** 数字钩子暴露冲突，稳定A备注建立场景，A末尾高亮解释局部动机，B尾号沿曲线移入输出解释因果，三项状态呈现决策与未验证部分。
8. **可保存资产：** 编号01–05的3+2“Prompt改动前检查卡”，保留前后同跑；末尾无字幕停留供阅读。能否实际带走方法须真实盲看验证。

## 制作与审片备注

- 分组保持2句钩子／2句背景与旧错／4句候选动作与反证／7句机制与检查／5句行动卡。A通过仅是局部证据，B的固定预期始终为80。
- 全程标“合成示例／非模型实测”；三项事实保持修复✓、保护✗、留出未测；逐组揭示，s14才显著呈现新版退回。s15的条件句不能触发实际通过画面。
- 字幕48px，使用全宽底部渐变、无边框；最终2.6秒不显示字幕。卡片保留五项行动，不以勾选状态暗示实际完成。
- 音色沿用`zh-CN-YunxiNeural`；s08与s19使用`+0%`，其余`+6%`，停顿按句设置。口播仅说“看个例子”；合成／非实测说明保留在画面和制作文档。文本变化必须重新生成音频与时间轴，不复用v3.1时长与审片结论。
- 复用现有Remotion运行时与视觉组件。最终场景快照与整条声音、动画、节奏均需针对v3.4复核；Agent自检不构成人工批准。
- 真实盲看应记录“原判断→改变判断的事实→下次行动”，并指出仍需猜的背景。当前未执行，不以方法设计稿宣称已验证有效。
