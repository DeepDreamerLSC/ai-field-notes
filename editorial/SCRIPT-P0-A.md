## 制作备注

- **v2 修订记录（对应 PR #7 行内批注）**：①"大多数项目""大部分企业答案在前两档"等分布性表述已删除，改为"常见的开局"（Interpretation 级修辞）与条件化的"图里没有这类需求就停在前两格"；②"拿不到就编出来"改为"要么答不了，要么只能猜"，并在第二问并入权限、例外与人工兜底；③ Agent 定义从"只有…才轮得到"放宽为"典型场景 + 条件判断"。
- **安全稿红线**：不出现客户行业、规模、任何真实案例；诊断图与三档判断均为方法示意，片内标"示意/示例"；全片无 ROI、无收益数字。
- **TTS 试听点**：「答不了」「兜底」的停顿处理；"猜错了算谁的"语气需上扬，建议人工配音试一遍对比。
- 字幕 = 旁白逐句常驻底部安全区；A3 诊断图为首片唯一专属组件（三栏 + 结论栏），不预建其他选题的图形类型。
- 首片画面最小集：字卡 / 流程条 / 诊断图 / 字幕轨；先做静态图 + 剪辑基线并计时，再决定是否引入渲染器。
