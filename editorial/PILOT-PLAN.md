## 1. 成片顺序（人工裁定 2026-10-05，详见 RULING-2026-10-05.md）

**#2 首发 → #3 第二（等 #2 真实反馈）→ #5 条件候选（单独安全门，不过则延后）→ #4 延后（扩展三维度）。样片只做 #2。**

裁定要点：

- 频道定位：**面向企业 AI 落地的实践与决策记录**（企业经营者 + 技术负责人双受众）；适合首发的内容不一定是技术含量最高的内容。
- 创作角色原推荐序（B→A→C）已被人工裁定替代；差异主要在"潜在客户相关性"权重高于"钩子锋利度"。
- #3 脚本按裁定改写标题与开场，从一次改动的正反结果切入；#4 从"净删除"单一标准扩展为职责替代、行为等价、长期维护成本三维度。
- P1-D（#5 电商）保留商业价值但安全门不降级，审查不过直接延后。

**样片制作前置门：#2 的公开安全稿（`SCRIPT-P0-A.md`）须经人工确认，才进入 Markdown → 脚本 → 分镜 → 视频。** Remotion 仅为候选工具，简单图文剪辑更快更稳则弃用（见第 6 节 FALLBACK 线）。

## 2. 最小生产链路落法

```
人工批准的 public-safe 观点（Issue #3 正文）
  → 90–115s 视频脚本
  → 分镜表（图形/文字/时长/旁白）
  → scene 数据（结构化 JSON）
  → Remotion 一套有限模板（本地）
  → 渲染 MP4（1080×1920）
  → 人工审片（事实/画面/声音/隐私/节奏）
  → 手工发布（发布权在人）
  → 反馈与成本记录回 #6
```

禁止项照单执行：不导入 private repo Issue / 未脱敏日志；不上传发布机器人、素材 DB、调度队列；不预建通用平台。

## 3. 一套有限 Scene 机制（一次开发，三条选题复用）

| Scene | 用途 | 要点 |
| --- | --- | --- |
| 字卡 | hook / 金句 / 章节 | 大字 + 副标，单一入场动画 |
| 流程条 | 路径 / 步骤 | 框 + 箭头，支持逐个点亮与变红 |
| 对照 | 双路径 / 双结局 / 双 owner | 左右或上下两栏，单栏状态切换 |
| 列表 | 编号要点 | 逐条入场，单屏最多 4 条 |
| 图表 | 判断树 / 分叉 / 圆环 / 账本 | 节点 + 连线，支持分叉与淡出动画 |
| 字幕轨 | 常驻底部 | 与旁白时间轴对齐，样式全局统一 |

**9:16 规范**：1080×1920；顶部约 15%、底部约 20% 为平台 UI 避让区，字幕与关键文字全部落在安全区内；最小正文字号在首渲染后按成片观感校准。
