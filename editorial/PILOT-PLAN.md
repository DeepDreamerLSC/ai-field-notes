## 3. 首片画面：最小实现，先基线后工具

**先做静态图 + 剪辑的成本基线并计时**；渲染器（如 Remotion）只有当基线证明"这类画面会重复到值得自动化"时才引入——顺序是 **基线 → 对比 → 选型**，不为工具而工具。

首片仅实现 #2 所需的 4 类画面，**不预建 #3/#4 的图形类型**：

1. 字卡（hook / 金句 / 标题）
2. 流程条（错误路径，逐步点亮变红）
3. 诊断图组件（三栏：流程 / 数据与边界 / 验收 + 结论栏）
4. 字幕轨（常驻底部，与旁白对齐）

9:16 规范：1080×1920；顶部约 15%、底部约 20% 为平台 UI 避让区；最小字号首渲染后校准。
后续选题需要的新画面（三组样本矩阵、圆环、账本等）**按条按需追加**，凭真实成本数据决定，不在首片预支。
