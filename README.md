# AI Field Notes

> 记录 AI 从技术探索走向真实业务落地过程中的判断、实践与方法沉淀。

## 项目定位

`ai-field-notes` 不是一个单独的研究项目，也不是为了追热点建立的内容账号仓库。

它是一个公开表达层：

```
真实项目实践
      ↓
问题与失败
      ↓
方法提炼
      ↓
脱敏整理
      ↓
公开内容
```

核心目标：让外部世界看到真实 AI 落地过程中的问题、判断和经验。

## 内容来源

主要来源于：

- edu-agent：AI 教育智能体、评测体系、Harness 演进
- shoes-discovery：制造业 AI 场景探索
- ai-intelligence：外部技术趋势与方法研究
- 后续真实客户项目

## 内容原则

### 1. 不为了内容创造项目

所有内容应该来自真实问题、真实实践和真实判断。

### 2. 不泄露业务敏感信息

进入本仓库前需要完成公开化处理：

```
内部事实
→ 抽象问题
→ 方法总结
→ 公开表达
```

### 3. 区分事实、判断和观点

每篇内容尽量说明：

- 观察到了什么事实
- 基于什么证据形成判断
- 哪些地方仍然存在不确定性

## 内容类型

### Field Note

来自真实项目过程中的观察。

例如：

- 为什么 Agent 优化不能只改提示词
- 为什么评测体系比模型选择更重要

### Method

从实践中抽象出的通用方法。

例如：

- Eval Harness 设计原则
- AI 项目验证流程

### Case Study

具备完整结果的数据化案例。

结构：

```
问题
→ 原始状态
→ 解决方案
→ 结果
→ 局限
```

### Thought

阶段性观点和行业判断。
